# 养殖场信息管理 App UI 设计

## 设计概述

本设计基于产品需求文档，同时参考了旧版截图（old-*.jpg），为养殖场信息管理 App 提供了高保真的 UI 设计。设计采用绿色系作为主色调，代表农业和自然，符合养殖场管理的主题。

## 设计风格

- **主色调**：绿色 (#4CAF50)
- **辅助色**：白色 (#FFFFFF)、浅灰色 (#F5F5F5)、深灰色 (#333333)
- **按钮样式**：圆角矩形按钮，主操作按钮使用主色调
- **字体**：无衬线字体，标题 18px，正文 14px，辅助文字 12px
- **布局风格**：卡片式布局，清晰的视觉层次
- **图标风格**：简洁的表情符号图标，保持一致性
- **设计特点**：现代简约风格，既美观又实用，避免过度装饰

## 设计改进

### 视觉优化
- **更大的圆角**：使用 16px 圆角，营造更现代的视觉效果
- **增强的阴影**：使用更深层的阴影，提升层次感
- **更丰富的间距**：增加内边距和外边距，提升呼吸感
- **微妙的交互**：添加悬停效果和过渡动画
- **视觉引导**：使用左侧边框等元素引导视觉焦点

### 页面具体改进
- **登录页**：增大容器尺寸，增强阴影效果，提升整体质感
- **首页**：改进卡片设计，添加左侧绿色边框，增强悬停效果
- **养殖场详情页**：优化信息展示，改进文件列表项设计
- **新增养殖场页**：改进表单布局，优化上传区域设计
- **搜索结果页**：保持整体设计风格一致

### 功能保持
- **字段一致性**：所有核心字段与旧页面保持一致
- **功能完整性**：保留所有原有功能
- **操作流程**：保持原有操作流程不变

## 页面设计

### 1. 登录页 (login.html)
- 应用 Logo 和名称
- 用户名和密码输入框
- 记住密码选项
- 登录按钮
- 注册链接（暂时关闭）

### 2. 首页 (index.html)
- 顶部标题栏
- 搜索栏
- 养殖场卡片列表
- 新增按钮（悬浮按钮）
- 上拉加载更多

### 3. 养殖场详情页 (farm-detail.html)
- 返回按钮和标题
- 养殖场基本信息
- 图片网格展示
- 文件列表（支持下载和分享）
- 底部编辑和删除按钮

### 4. 新增养殖场页 (farm-add.html)
- 返回按钮、标题和保存按钮
- 表单输入（名称、地址、类型、规模等）
- 图片上传区域
- 文件上传区域
- 已上传文件/图片管理

### 5. 搜索结果页 (search-results.html)
- 返回按钮和标题
- 搜索栏（带搜索按钮）
- 筛选条件
- 搜索结果列表
- 结果数量提示

## 交互设计

- **触摸反馈**：按钮点击有视觉反馈
- **平滑过渡**：页面切换和操作有平滑的过渡动画
- **加载状态**：数据加载时有加载提示
- **错误提示**：操作错误时有错误提示
- **空状态**：无数据时有友好的空状态提示

## 响应式设计

- **移动优先**：专为安卓手机设计
- **屏幕适配**：支持主流安卓手机屏幕尺寸
- **触摸优化**：按钮和可点击区域大小适合手指点击
- **字体大小**：确保在不同屏幕尺寸下文字清晰可读

## 使用方法

1. 直接在浏览器中打开 HTML 文件查看设计效果
2. 可以使用浏览器的开发者工具模拟移动设备视图
3. 点击页面元素可以体验交互效果

## 注意事项

- 本设计为高保真原型，实际开发时需要根据技术实现进行适当调整
- 图片和文件上传功能在原型中为模拟效果，实际开发需要集成相应的 API
- 所有页面都保持了一致的设计风格，确保用户体验的连贯性
