## 使用方法

### 直接使用 SVG

1. 从 `icons.svg` 文件中复制所需图标的 SVG 代码
2. 粘贴到您的组件中
3. 根据需要调整颜色、大小等属性

## 设计规范

### 图标风格
- **风格**：线性图标（Outline）
- **线宽**：2px
- **圆角**：2px
- **尺寸**：24×24px（标准）

### 颜色规范
- **默认颜色**：#4CAF50（生态绿）
- **悬停颜色**：#81C784（浅绿色）
- **禁用颜色**：#999999（浅灰色）

### 布局规范
- 图标与文字之间的间距：8px
- 图标在按钮中的边距：12px
- 图标在卡片中的大小：48×48px

## 自定义指南

### 颜色修改
```svg
<!-- 修改 stroke 属性 -->
<path d="..." stroke="#4CAF50" />
```

### 大小调整
```svg
<!-- 修改 width 和 height 属性 -->
<svg width="32" height="32" viewBox="0 0 24 24">
  <!-- 图标路径 -->
</svg>
```

### 动画效果
可以为图标添加简单的动画效果，如旋转、缩放等：

```css
.icon-rotate {
  animation: rotate 2s linear infinite;
}

@keyframes rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
```

## 最佳实践

1. **保持一致性**：在整个应用中使用相同风格的图标
2. **合理使用**：只为有意义的操作使用图标
3. **搭配文字**：对于重要操作，建议图标与文字搭配使用
4. **响应式设计**：根据屏幕尺寸调整图标大小
5. **可访问性**：为图标添加适当的 aria-label
