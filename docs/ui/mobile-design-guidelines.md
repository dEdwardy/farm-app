# 渔场管家 - 移动端设计规范

## 设计原则

### 1. 移动优先
- 设计应以移动设备为主要目标
- 确保在小屏幕上的良好体验
- 逐步增强到大屏幕设备

### 2. 响应式设计
- 使用媒体查询适配不同屏幕尺寸
- 灵活的布局系统
- 自适应的字体和图标大小

### 3. 性能优化
- 优化SVG文件大小
- 减少不必要的动画和效果
- 确保页面加载速度快

### 4. 触摸友好
- 按钮和交互元素尺寸不小于44×44px
- 适当的触摸反馈
- 避免过于密集的交互元素

## 页面规范

### 引导页 (onboarding.html)

#### 布局
- 最大宽度：414px
- 内边距：30px（移动端20px）
- 垂直居中布局

#### 响应式断点
- 小屏幕 (< 375px)：调整字体大小和内边距
- 中等屏幕 (375px - 414px)：标准布局
- 大屏幕 (> 414px)：保持最大宽度414px

#### 交互体验
- 平滑的动画过渡效果
- 自动轮播的步骤指示器
- 触摸友好的按钮尺寸

### 启动页 (splash.html)

#### 布局
- 全屏布局
- 垂直居中的内容
- 简洁的视觉设计

#### 响应式设计
- 自适应的Logo大小
- 响应式字体大小
- 保持视觉比例一致

#### 性能考虑
- 最小化SVG文件大小
- 优化动画性能
- 快速加载时间

## 图标规范

### 应用图标

#### 尺寸要求
- iOS：1024×1024px（App Store）
- Android：512×512px（Play Store）
- 启动图标：192×192px
- Favicon：32×32px

#### 设计要求
- 圆角处理：180px（1024×1024）
- 清晰的视觉识别
- 符合品牌色彩规范

### 功能图标

#### 尺寸规范
- 标准尺寸：24×24px
- 小尺寸：20×20px
- 大尺寸：32×32px

#### 设计风格
- 线性图标（Outline）
- 线宽：2px
- 圆角：2px
- 一致的视觉语言

## 色彩规范

### 移动端色彩应用
- 主色调：#4CAF50（生态绿）
- 辅助色：#2196F3（水蓝）
- 背景色：白色或浅色背景
- 文字色：深色文字确保可读性

### 色彩对比度
- 确保文本与背景的对比度符合WCAG AA标准
- 重要信息使用高对比度
- 辅助信息使用低对比度

## 交互规范

### 触摸反馈
- 按钮点击应有视觉反馈
- 平滑的过渡动画
- 适当的触摸区域大小

### 动画效果
- 适度使用动画增强用户体验
- 避免过度动画影响性能
- 确保动画流畅不卡顿

### 导航设计
- 清晰的导航结构
- 易于理解的图标
- 一致的导航模式

## 性能优化

### SVG优化
- 移除不必要的属性
- 简化路径
- 合并相似元素

### 页面加载
- 最小化CSS和JavaScript
- 优化图片和图标
- 确保快速的首屏加载时间

### 动画性能
- 使用CSS transforms和opacity进行动画
- 避免频繁的重排和重绘
- 考虑使用requestAnimationFrame

## 最佳实践

1. **测试不同设备**：在多种移动设备上测试设计
2. **保持简洁**：避免过度设计和不必要的元素
3. **关注细节**：确保所有交互元素都有适当的反馈
4. **持续优化**：根据用户反馈不断改进设计
5. **遵循平台规范**：了解并遵循iOS和Android的设计指南
