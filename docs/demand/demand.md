# 养殖场信息管理 App 需求文档

## 1. 需求背景

用户需要一个个人使用的养殖场信息管理应用，用于安卓手机，主要功能包括：
- 手动录入养殖场信息
- 修改养殖场信息
- 查找养殖场信息
- 登录功能
- 图片和文件上传功能

## 2. 功能需求（Functional Requirements）

| 编号 | 功能点 | 用户故事 | 输入/输出/流程 | 详细说明 |
|------|--------|---------|---------------|----------|
| FR1 | 用户登录 | 作为用户，我希望能够登录应用，以便访问我的养殖场信息 | 输入：用户名、密码<br>输出：登录成功/失败提示<br>流程：输入凭据 → 验证 → 进入首页 | 支持用户名和密码登录，可选择记住密码 |
| FR2 | 用户注册 | 作为新用户，我希望能够注册账号，以便使用应用 | 输入：用户名、密码、确认密码<br>输出：注册成功/失败提示<br>流程：填写信息 → 验证 → 注册成功 | 用户名需唯一，密码长度不少于6位（暂时关闭，后续可能开放） |
| FR3 | 养殖场列表 | 作为用户，我希望查看所有养殖场信息，以便快速了解整体情况 | 输入：无<br>输出：养殖场列表<br>流程：进入首页 → 加载列表 | 支持下拉刷新和上拉加载更多 |
| FR4 | 新增养殖场 | 作为用户，我希望能够添加新的养殖场信息，以便记录新的养殖场 | 输入：养殖场名称、地址、类型、规模等信息<br>输出：添加成功/失败提示<br>流程：填写表单 → 上传图片/文件 → 保存 | 支持填写详细信息和上传相关资料 |
| FR5 | 编辑养殖场 | 作为用户，我希望能够修改现有养殖场信息，以便更新信息 | 输入：修改后的养殖场信息<br>输出：修改成功/失败提示<br>流程：进入详情页 → 点击编辑 → 修改信息 → 保存 | 保持原有数据，只修改变更部分 |
| FR6 | 删除养殖场 | 作为用户，我希望能够删除不需要的养殖场信息，以便保持数据整洁 | 输入：确认删除操作<br>输出：删除成功/失败提示<br>流程：进入详情页 → 点击删除 → 确认 → 删除 | 删除前需要确认，删除后不可恢复 |
| FR7 | 搜索养殖场 | 作为用户，我希望能够搜索养殖场，以便快速找到特定养殖场 | 输入：搜索关键词<br>输出：搜索结果列表<br>流程：输入关键词 → 点击搜索 → 查看结果 | 支持按名称、地址等字段搜索 |
| FR8 | 图片上传 | 作为用户，我希望能够上传养殖场相关图片，以便直观了解养殖场情况 | 输入：选择的图片<br>输出：上传成功/失败提示<br>流程：点击上传 → 选择图片 → 上传 | 支持多张图片上传，显示上传进度 |
| FR9 | 文件上传 | 作为用户，我希望能够上传相关文件，以便存储养殖场相关资料 | 输入：选择的文件<br>输出：上传成功/失败提示<br>流程：点击上传 → 选择文件 → 上传 | 支持多种文件类型，显示上传进度 |
| FR10 | 图片预览 | 作为用户，我希望能够预览上传的图片，以便查看图片详情 | 输入：点击图片<br>输出：图片预览界面<br>流程：点击图片 → 进入预览模式 → 查看图片 | 支持缩放和滑动切换图片 |
| FR11 | 文件下载 | 作为用户，我希望能够下载上传的文件，以便查看文件内容 | 输入：点击下载按钮<br>输出：文件下载到本地<br>流程：点击下载 → 下载文件 → 提示完成 | 支持各种类型文件的下载 |

## 3. 非功能需求（Non-Functional Requirements）

| 编号 | 需求点 | 详细说明 |
|------|--------|----------|
| NFR1 | 性能要求 | 应用启动时间不超过3秒，页面切换流畅，列表加载速度快 |
| NFR2 | 可用性 | 界面简洁直观，操作流程简单，适合非技术用户使用 |
| NFR3 | 可靠性 | 数据存储安全可靠，防止数据丢失，支持数据备份 |
| NFR4 | 兼容性 | 支持主流安卓手机型号，适配不同屏幕尺寸 |
| NFR5 | 安全性 | 密码加密存储，数据隔离，防止未授权访问 |
| NFR6 | 离线功能 | 暂时不做要求 |
| NFR7 | 存储管理 | 有效管理本地存储，避免存储空间过度使用 |

## 4. 数据需求

| 编号 | 数据点 | 数据结构 | 存储方式 |
|------|--------|----------|----------|
| DR1 | 用户数据 | 包含用户ID、用户名、密码等信息 | Supabase Auth |
| DR2 | 养殖场数据 | 包含养殖场ID、名称、地址、类型、规模等信息 | Supabase 数据库 |
| DR3 | 图片数据 | 包含图片ID、养殖场ID、存储路径等信息 | Supabase 数据库 + 阿里云 OSS |
| DR4 | 文件数据 | 包含文件ID、养殖场ID、存储路径、文件名、大小等信息 | Supabase 数据库 + 阿里云 OSS |

## 5. 范围限定

| 编号 | 边界/范围限定 | 说明 |
|------|--------------|------|
| SC1 | 仅个人使用 | 应用设计为个人使用，不支持多用户协作 |
| SC2 | 云存储 | 使用 Supabase 作为后端数据库，阿里云 OSS 作为文件存储 |
| SC3 | 安卓平台 | 仅支持安卓手机，不支持iOS或其他平台 |
| SC4 | 手动录入 | 数据需要手动录入，不支持自动采集或导入 |
| SC5 | 基本功能 | 专注于核心功能，不包含高级分析或报表功能 |
| SC6 | Supabase 免费版 | 使用 Supabase 个人用户免费版本，可能存在功能限制 |

## 6. 验收标准

| 编号 | 功能点 | 验收标准 |
|------|--------|----------|
| AC1 | 登录注册 | 能够成功注册新账号并登录，登录状态保持正常 |
| AC2 | 养殖场管理 | 能够成功新增、编辑、删除养殖场信息，数据保存正确 |
| AC3 | 搜索功能 | 能够根据关键词搜索养殖场，搜索结果准确 |
| AC4 | 图片上传 | 能够成功上传多张图片，图片显示正常，支持预览 |
| AC5 | 文件上传 | 能够成功上传各种类型文件，文件可下载和查看 |
| AC6 | 性能 | 应用启动和页面切换流畅，列表加载速度快 |
| AC7 | 离线功能 | 暂时不做要求 |
| AC8 | 数据安全 | 数据存储安全，密码加密，应用退出后需要重新登录 |

## 7. 风险/依赖备注

| 类型 | 关联编号/功能点 | 具体内容/说明 | 备注 |
|------|----------------|--------------|------|
| 风险 | FR8/FR9 | 大量图片和文件上传可能导致阿里云 OSS 存储空间不足 | 建议定期清理不需要的文件 |
| 风险 | NFR4 | 不同安卓手机型号的适配可能存在差异 | 建议在主流机型上进行测试 |
| 风险 | 整体功能 | Supabase 免费版可能存在 API 调用次数限制 | 注意监控 API 使用情况 |
| 依赖 | FR1/FR2 | 依赖 Supabase Auth 进行用户认证 | 确保 Supabase 项目配置正确 |
| 依赖 | FR3/FR4/FR5/FR6/FR7 | 依赖 Supabase 数据库存储数据 | 确保数据库表结构设计合理 |
| 依赖 | FR8/FR9 | 依赖 Expo ImagePicker 和 DocumentPicker | 确保权限配置正确 |
| 依赖 | FR8/FR9 | 依赖 Supabase Edge Functions 和阿里云 OSS 进行文件存储 | 确保 Edge Functions 部署成功，OSS 配置正确 |
| 依赖 | 整体功能 | 依赖 React Native 和 Expo 框架 | 确保依赖版本兼容性 |
